# نصب آسان ویندوز

## یک نگاه

```text
دانلود Setup از GitHub Actions
        ↓
  دوبار کلیک روی EXE
        ↓
     START / چت
        ↓
   افزودن فایل .gguf
```

## Artifact درست

| نام تقریبی | استفاده |
|------------|---------|
| `GGUF-Runner-Setup-*` | **همین را نصب کنید** |
| `GGUF-Runner-portable-*` | فقط سورس؛ نصب کامل آفلاین نیست |

همراه Setup معمولاً `SHA256SUMS.txt` است.

## بعد از نصب

1. `START.bat` یا میانبر استارت  
2. کشو → **مدل‌ها** → **افزودن مدل**  
3. **لود** → **چت** یا **ترمینال**  

## مشکل‌های رایج

| مشکل | کار |
|------|-----|
| tkinter / customtkinter | Setup آفلاین ناقص — دوباره از Actions سبز بگیرید |
| مدل لود نمی‌شود | مدل کوچک‌تر / `GPU layers = 0` / رم بیشتر |
| برنامه باز نمی‌شود | `Doctor` از داخل Hub یا `scripts\doctor.bat` |
